# 🤖 Julia: Interactive Python Chatbot

A conversational chatbot built in Python that simulates a real interactive dialogue, awarded best project in class on the Algorithmics platform.

---

## 💡 About

Julia is a terminal-based chatbot that greets you by name and holds a natural conversation. You can either type `menu` to explore what Julia can do, or just talk naturally, if you type "do you have a game?" Julia will detect the word and take you there directly, no exact command needed.

This was a class project where students competed to build the most engaging chatbot. Julia won first place, receiving the most likes, comments, and interactions on the Algorithmics platform.

---

## 🗣️ How It Works

- Julia asks your name and uses it throughout the conversation
- Type `menu` to see all available topics
- Or just type naturally; Julia detects keywords in your sentences
- Type `end` to finish the conversation
- At the end, Julia tells you how long you've been talking

---

## 📋 What Julia Can Talk About

- Music: recommendations by genre (Rap, Pop, Jazz, Classical, Heavy Metal)
- Movies: recommendations by genre (Action, Comedy, Drama, Fantasy, Horror, Sci-Fi, Documentary)
- Latest News: by region (Morocco, Africa, Europe, Asia, Australia, North America, South America)
- Life Tips: Time Management, Stress, Healthy Habits, Communication, Goals
- Python Home Practice: resources and advice for self-learning
- Games: Mad Libs and Rock Paper Scissors

---

## 🚀 How to Run

```bash
python Chatbot.py
```
No installations needed, built with Python's standard library only.

---

## 🛠️ Built With

- Python 3
- `time` module: to track conversation duration
- `random` module: for Mad Libs and Rock Paper Scissors
